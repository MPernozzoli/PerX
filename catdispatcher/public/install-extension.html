Estensione CAT Dispatcher

Assegna i CAT direttamente dal gestionale ACT JellyFish

Scarica Estensione

Come installare

1

Scarica il file ZIP

Clicca sul pulsante "Scarica Estensione" qui sopra. Il file verrà salvato nella cartella Download del tuo computer.

2

Estrai il contenuto

Fai doppio clic sul file chrome-extension.zip per estrarlo. Verrà creata una cartella con i file dell'estensione.

3

Apri le estensioni di Chrome

Apri Chrome e vai all'indirizzo chrome://extensions oppure clicca sui tre puntini in alto a destra → Estensioni → Gestisci estensioni.

4

Attiva la Modalità sviluppatore

In alto a destra nella pagina delle estensioni, attiva l'interruttore "Modalità sviluppatore".

5

Carica l'estensione

Clicca su "Carica estensione non pacchettizzata" e seleziona la cartella che hai estratto al passo 2.

6

Fissa l'icona nella barra (consigliato)

Clicca sull'icona del puzzle delle estensioni nella barra di Chrome, individua CAT Dispatcher e clicca sul pin accanto al nome per tenerla sempre visibile e a portata di mano.

7

Fatto!

L'estensione è ora installata. Vedrai l'icona CAT Dispatcher nella barra degli strumenti di Chrome. Vai su ACT JellyFish per usarla!

Importante – la cartella deve rimanere sul dispositivo

Quando installi l'estensione in modalità sviluppatore, Chrome legge i file direttamente dalla cartella che hai selezionato. Non eliminarne il contenuto dopo l'installazione: se cancelli o sposti la cartella estratta dallo ZIP, l'estensione smetterà di funzionare.

Nota:

L'estensione funziona solo sul gestionale ACT JellyFish (act.jfish.it). Devi essere loggato con il tuo account per usarla.
