Privacy Policy

ACT CAT Dispatcher - Estensione Chrome

Ultimo aggiornamento: Gennaio 2026

Introduzione

Questa Privacy Policy descrive come l'estensione "ACT CAT Dispatcher" gestisce i dati degli utenti. La tua privacy è importante per noi e ci impegniamo a proteggere le informazioni personali.

In sintesi: L'estensione non raccoglie, non memorizza e non condivide alcun dato personale con terze parti.

Dati raccolti

L'estensione ACT CAT Dispatcher:

  • NON raccoglie dati personali
  • NON traccia la navigazione dell'utente
  • NON invia dati a server di terze parti per analytics o pubblicità
  • NON accede a dati al di fuori del sito act.jfish.it

Dati memorizzati localmente

L'estensione memorizza localmente (solo sul tuo dispositivo) i seguenti dati:

  • Token di autenticazione: Per mantenere la sessione di login a Cat Dispatcher. Questi token sono salvati in modo sicuro usando l'API chrome.storage.local e non vengono mai condivisi.
  • Email utente: Solo per mostrare l'account connesso nell'interfaccia dell'estensione.

Questi dati vengono cancellati quando effettui il logout dall'estensione.

Dati letti dalle pagine web

L'estensione legge dati esclusivamente dalle pagine del gestionale ACT (act.jfish.it) per fornire le sue funzionalità:

  • Indirizzo, città, CAP, provincia e nazione dell'ubicazione rischio del sinistro
  • Il CAT attualmente assegnato al sinistro

Questi dati vengono utilizzati solo localmente per mostrare le informazioni nell'estensione e per chiamare l'API di Cat Dispatcher per l'assegnazione automatica del CAT. Non vengono memorizzati permanentemente né condivisi con terze parti.

Comunicazioni di rete

L'estensione comunica esclusivamente con:

  • API Cat Dispatcher (Supabase): Per autenticazione e ricerca del CAT corretto in base all'ubicazione

Tutte le comunicazioni avvengono tramite connessioni HTTPS sicure.

Permessi richiesti

L'estensione richiede i seguenti permessi Chrome:

  • activeTab: Per leggere i dati dalla pagina ACT attualmente aperta
  • scripting: Per iniettare lo script che legge/scrive i dati nella pagina
  • storage: Per salvare i token di autenticazione localmente
  • Host permissions (act.jfish.it): Per funzionare sul gestionale ACT
  • Host permissions (supabase.co): Per comunicare con l'API di Cat Dispatcher

Sicurezza

Adottiamo misure di sicurezza appropriate per proteggere i dati:

  • I token di autenticazione sono salvati in modo sicuro usando chrome.storage.local
  • Tutte le comunicazioni API avvengono tramite HTTPS
  • L'estensione funziona solo sul dominio autorizzato (act.jfish.it)
  • Non vengono utilizzati script di terze parti per tracking o analytics

Modifiche alla Privacy Policy

Potremmo aggiornare questa Privacy Policy periodicamente. Ti consigliamo di consultare questa pagina regolarmente per eventuali modifiche.

Contatti

Per domande o richieste relative alla privacy, contatta l'amministratore del servizio Cat Dispatcher.
