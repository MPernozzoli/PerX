# PerX Insight Studio (landing marketing)

Landing di `perx.it`: home `/`, percorso prodotto `/come-funziona`.
Dettaglio → vault
[`Documentation/Piattaforme/Altre-Web-App.md`](../../Documentation/Piattaforme/Altre-Web-App.md).

## Comandi

Dalla root del monorepo o da questa cartella:

```sh
npm install
npm run dev
npm run check
npm run build
```

## Screenshot della pratica demo

1. Cattura le schermate elencate in `src/content/pratica-demo.ts` (stessi dati inventati).
2. Salva i PNG in `src/assets/story/` con i filename previsti.
3. Registra l’import in `src/components/story/story-assets.ts`.
